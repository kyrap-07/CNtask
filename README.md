# CampusLife — SRM Campus Companion

CampusLife is a Flutter-based campus companion application designed for SRM students. It aims to make campus life more organised by bringing useful academic information and reminders into one place.

## Features

* **Campus Dashboard:** A central place to access campus-related information.
* **Exam Reminders:** Helps students keep track of upcoming examinations.
* **Academic Organisation:** Designed to make important academic updates easier to manage.
* **Authentication:** Firebase Authentication with email and password.
* **Student-Focused Design:** Built with a focus on simplicity and usability.

## Tech Stack

* **Frontend:** Flutter, Dart
* **Authentication:** Firebase Authentication
* **Backend Services:** Firebase
* **Version Control:** Git and GitHub
* **Deployment:** GitHub Pages

## Getting Started

### Prerequisites

* Flutter SDK
* Dart SDK
* Git

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/kyrap-07/CNtask.git
   ```

2. Navigate to the project directory:

   ```bash
   cd CNtask
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run -d chrome
   ```

Firebase configuration must be set up correctly for authentication to work.
